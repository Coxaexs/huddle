# Servers & Channels

## What is a server?

A server is a shared home for a group of friends. Inside it are text channels, voice rooms, roles, and settings. You can belong to as many servers as you want and create as many as you want. The servers you're in sit on the server rail on the far left with their initials (for example, **PE**).

## Creating a server

1. Click the **+** (**Create Server**) button on the server rail.
2. Choose **Create New** in the window that opens.
3. Give your server a name and click **Create Server**.

Your new server comes ready with one text channel (**#general**) and one voice room (**General Voice**). You can rename or delete them anytime.

> **Coming from Discord:** If you paste a Discord server template link (`discord.new/…`) into the name box, that server's channels, roles, and permissions are copied into your new Hoffle server.

## Joining a server with an invite code

If a friend gave you just a code instead of a link:

1. Click **+** on the server rail.
2. Choose **Join with Code**.
3. Paste the code and confirm.

![Add server dialog](/help-media/img/sunucu-ekle-penceresi.webp)

The compass icon on the server rail (**Explore public servers**) shows servers that have listed themselves publicly; you can join those without an invite.

## Inviting friends

1. Click the person icon (**Create Invite**) next to the server name. The same option is in the menu when you click the server name.
2. Your Hoffle friends appear in the list; click **Invite** next to anyone you want to invite. The invite goes to them as a direct message.
3. For someone not on Hoffle yet, click **Copy** to copy the invite link and send it anywhere. The **WhatsApp** and **Telegram** buttons open the link directly in those apps, and **QR code** shows a code scannable with a phone camera.

::video davet-et | Inviting friends to a server

![Invite dialog](/help-media/img/davet-penceresi.webp)

To change how many people can use an invite link and when it expires, click **Edit invite link** at the bottom of the dialog. To see and revoke all invites, go to **Server Settings → Invites**.

## Channel types

You can create five types of channels in a server:

| Type | Icon | What it's for |
| --- | --- | --- |
| **Text channel** | `#` | Regular chat channel where everyone reads and writes. |
| **Voice room** | speaker | Voice and video chat room you click to join. Music bot, Watch Together, and games also run here. |
| **Announcement** | broadcast icon | A channel where only admins can post and everyone can read. Other servers can **follow** it to receive announcements in their own channels. |
| **Forum** | speech bubble | A channel where each topic is its own thread. Great for suggestions, questions, and lists. |
| **Stage** | people icon | A voice room where one speaker or a small group talks while others listen. Built for talks and events. |

## Creating channels and categories

**To create a channel:**

1. Click the **+** (**Create Channel**) button next to **Channels** at the top of the channel list.
2. Pick the channel type: **Text channel**, **Voice room**, **Announcement**, **Forum**, or **Stage**.
3. Type a name and click **Create Channel**.

The **+** button on a category header creates the channel directly inside that category.

::video kanal-olustur | Creating a text channel and a voice room

![Channel type menu](/help-media/img/kanal-turu-menusu.webp)

**To create a category:** Click the other button next to **Channels** (**Add Category**), give the category a name, and click **Create Category**. Categories group channels (for example "Chat", "Voice Rooms", "Games & D&D") and can be collapsed or expanded with the arrow in their header. You can drag and drop channels to reorder them or move them between categories.

## Channel settings

Right-click a channel (long-press on mobile). In the menu:

- **Notifications:** *All messages*, *Only @mentions*, or *Nothing* for this channel. Under **Mute**, you can mute the channel for 15 minutes, 1 hour, 8 hours, 24 hours, or indefinitely.
- **Rename** and **Edit topic:** The channel's name and the short description shown in the top bar.
- **Permissions:** Who can see and use the channel. Details in [Roles & Permissions](/en/help/roles#private-channels-and-channel-permissions).
- **Set Slowmode:** How long everyone must wait between sending two messages. Useful in busy channels.
- **Mark as age-restricted:** Marks the channel as visible to adults only.
- **Convert to …:** Turns a text channel into an announcement or forum channel (or back). Messages are not lost.
- **Delete channel:** Permanently deletes the channel and its messages.

## Server menu and server settings

Click the server name at the top of the channel list. The menu has:

- **Server Settings**
- **Create Invite**
- **Rename Server**
- **Create Channel**
- **Mark as Read:** Marks all unread messages in the server as read.
- **Notification level:** All messages, only @mentions, or nothing (muted).
- **Delete Server** (only visible to the server owner)

Inside **Server Settings**, you'll find:

| Section | What it does |
| --- | --- |
| **Server Profile** | Name, icon (photo), banner image or gradient, and up to 5 tags showing the server's interests. |
| **Emoji & Stickers**, **Stickers** | Upload custom emoji and stickers to the server. |
| **Soundboard** | Short sound clips that can be played in voice rooms. |
| **Members** | Member list, which invite each person joined through, and role assignment. |
| **Roles** | Creating roles and permissions. See [Roles & Permissions](/en/help/roles). |
| **Invites** | All invite links and revoking them. |
| **Access** | Listing the server publicly, making it readable on the web, and toggling server feature modules (D&D, mini-games, music, 3D Living Room). |
| **Welcome Screen** | Showing rules and an optional short intro form to newcomers. |
| **Integrations** | Bots, webhooks, feeds, and the Discord bridge. |
| **Safety & AutoMod**, **AutoMod**, **Audit Log**, **Bans** | Moderation tools. See [Moderation & Safety](/en/help/moderation). |
| **Server Template** | Template for copying the server's channel and role layout to other servers. |

## Welcome screen

If you want newcomers to see the server's rules before entering chat:

1. Open **Server Settings → Welcome Screen**.
2. Check **Show welcome screen to new members**.
3. Write the rules in the **Rules** box, one per line.
4. Optionally add a few questions in **Intro form** (**Add question**) or pick the preset *name, birth date, and short bio* form.
5. Click **Save Changes**.

The welcome screen is only shown to people who join after you turn this setting on.

![Welcome screen settings](/help-media/img/ayar-karsilama.webp)

## Turning server features on and off

Every server can turn off features it doesn't need. In **Server Settings → Access**, the **Server Feature Modules** list includes:

- **D&D & Tabletop:** Character sheets, battle maps, initiative tracker, and D&D lookup commands.
- **Mini-Games:** Chess, checkers, Connect Four, Wordle, poker, Uno, and trivia.
- **Music & Jam Synth:** Shared music player, synth keyboard, and music commands.
- **3D Living Room & Cinema:** 3D living room, meadow, and cinema hall.

Turning off a module hides its commands and buttons for everyone in that server. You can turn it back on anytime; nothing is deleted.
